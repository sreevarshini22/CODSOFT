# Task 1 - Genre Classification

This project is part of the CodSoft Internship.

## Objective
The objective of this task is to build a machine learning model that can classify the genre of a movie based on the given dataset.

## Files

- test_data.zip : Test dataset
- test_data_solution.zip : Solution dataset

## Technologies Used

- Pandas
- NumPy
