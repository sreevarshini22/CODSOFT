# Task 2 – Credit Card Fraud Detection

This project is completed as part of the **CodSoft Internship**.

## Objective

The objective of this task is to build a machine learning model that can detect fraudulent credit card transactions using transaction data.

## Dataset

The dataset used for this project is the **Fraud Detection Dataset**.

Dataset Source:
https://www.kaggle.com/datasets/kartik2112/fraud-detection

The dataset contains transaction details and a target column **is_fraud** which indicates whether a transaction is fraudulent or not.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Machine Learning

## Files in this Folder

* Fraud_detection.ipynb – Jupyter Notebook containing the implementation.
