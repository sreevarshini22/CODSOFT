# CODSOFT Internship Tasks

This repository contains the tasks completed as part of the **CodSoft Internship Program**.

## About

The objective of this internship is to gain practical experience by working on different machine learning and programming tasks.

## Tasks

### Task 1 – Genre Classification

Build a machine learning model that classifies the genre of movies based on the provided dataset.

### Task 2 – Spam SMS Detection

Develop a model to classify SMS messages as spam or ham.

### Task 3 – Customer Churn Prediction

Predict whether a customer will leave a service using machine learning techniques.

### Task 4 – Movie Recommendation System

Build a recommendation system that suggests movies to users based on preferences.

### Task 5 – Credit Card Fraud Detection

Create a model that identifies fraudulent credit card transactions.

## Technologies Used

* Python
* Machine Learning
* Pandas
* NumPy
* Scikit-learn
* Google Colab
